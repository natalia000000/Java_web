-Nuestro proyecto trata sobre una tienda de deportes, que contara con tres categorias de productos:
  Camisetas
  Articulos de gimnacio
  Calzado deportivo
  Cada uno estara separado por un div.
  
1. En el archivo index primero se vera un nav, que contendra "Tienda de deportes" y los enlaces a las otras paginas de la tienda,
    como los productos y el formulario de contacto.

  -En el Main se encuentra el titulo de la tienda, junto con la descripcion.

  -En el section se encontraran las targetas que contienen las categorias de nuestros productos, cada una separada por un div.
  Cada targeta contara con un boton para ir al apartado de productos.

2. En detalles nos encontraremos con el mismo nav que contiene los enlaces a las otras paginas.
  -En el Main iran todos los productos de las categorias mencionadas anteriormente, con cada categoria siendo separada por
   un section, y con cada producto siendo separado por un div.
